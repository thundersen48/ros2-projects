# ROS 2 Projects & Experiments

Репозиторий содержит учебные и практические проекты по робототехнике на базе **ROS 2**.

## 📁 Структура проекта

- `src/` — исходный код пакетов (роботы, учебные практики, узлы управления).
  - `diff_drive_bot/` — примитивный тестовый робот (дифференциальный привод).
  - `waffle/`, `SO-101/` — основные проекты симуляций и манипуляторов.
  - `practice_03/`, `practice_04/`, `practice_06/` — учебные лабораторные работы.
- `worlds/` — миры и 3D-модели окружения для Gazebo (`warehouse.world`).
- `cad_models/` — исходные 3D-модели компонентов.
